# u/skillity Landing Page

Prototype landing page — plain HTML/CSS starting point.

## Quick Start

```bash
open index.html
```

Or run a local server:
```bash
python3 -m http.server 8000
```

## Structure

```
├── index.html          # Landing page
├── styles.css          # Compiled CSS (Tailwind + custom)
└── CLAUDE.md           # Project docs
```

## Design System

**Fonts:** Crimson Pro (serif), Manrope (sans)
**Primary Color:** `#D63447`
**Background:** `#FBF6F2`

All CSS variables defined in `styles.css`.

## Deploy

Works on any static host — Netlify, Vercel, GitHub Pages, etc.

No build step required.
